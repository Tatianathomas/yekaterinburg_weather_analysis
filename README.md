# Weather Analysis of Yekaterinburg — Summer 2026

## Project description

This project analyzes weather data for Yekaterinburg during the summer of 2026 (June–August).

The data was collected from the Open-Meteo Archive API and analyzed using Python.

## Analytical questions

The project answers the following questions:

* How many days had precipitation?
* How many days had heavy precipitation (more than 3 mm)?
* How many nights had a minimum temperature below +3°C?
* How many days had a maximum temperature of +30°C or higher?
* How much precipitation fell during the summer?
* How did temperature and precipitation change throughout the summer?
* How did precipitation and average temperature vary by month?

## Tools and technologies

* Python
* pandas
* matplotlib
* requests
* Jupyter Notebook
* Open-Meteo API

## Analysis

The project includes:

* data collection via API;
* data transformation and cleaning;
* calculation of weather indicators;
* grouping data by month;
* analysis of temperature and precipitation;
* data visualization.

## Visualizations

The notebook contains visualizations of:

* daily average temperature;
* average temperature by month;
* daily precipitation;
* monthly precipitation;
* days with and without precipitation.

## Data source

Open-Meteo Archive API.

The dataset covers June 1 — August 31, 2026, for Yekaterinburg, Russia.
